| Layer | Selected Technology | Why It Wins |
| --- | --- | --- |
| Programming Language | Python | Best ecosystem for geospatial AI, ML, and scientific computing. |
| Data Processing | Google Earth Engine + Rasterio + GDAL + GeoPandas | Combines planetary-scale preprocessing with local geospatial analysis. |
| Spatial Database | PostgreSQL + PostGIS | Industry standard for spatial indexing, SQL, and GIS operations. |
| AI Framework | LightGBM + SHAP + Optuna | Fast, explainable, and optimized for structured geospatial features. |
| Physics Models | SOLWEIG + InVEST | Domain-validated urban climate simulation tools; avoid reinventing physics. |
| Optimization | PyMOO | Supports multi-objective optimization and Pareto analysis in one framework. |
| MCDA | PyDecision | Implements AHP, TOPSIS, PROMETHEE, and other decision methods. |
| Backend | FastAPI | High-performance Python APIs with excellent ML integration. |
| Frontend | React + MapLibre GL JS + ECharts + Material UI | Modern, interactive GIS dashboard with high-performance mapping. |
| Authentication | JWT | Lightweight and sufficient for the hackathon. |
| Object Storage | MinIO (future) / Local filesystem (hackathon) | Simple now, scalable later. |
| Deployment | Docker + Render/Railway | Fast hackathon deployment with a clean path to Kubernetes later. |
