# Module 1 — Urban Heat Hotspot Detection

### Objective

Predict current Urban Heat Island hotspots from satellite imagery and GIS features.

### Input

- Land Surface Temperature (LST)
- NDVI
- NDBI
- Albedo
- Land Use/Land Cover
- Elevation
- Population Density

### Recommended Model

## XGBoost Classifier

Why?

- Excellent with tabular environmental datasets
- Handles missing values
- High accuracy
- Fast training
- Widely used in remote sensing research

Alternative:

- Random Forest
- LightGBM

I would choose **XGBoost**.

---

# Module 3 — Future Temperature Prediction

This is where Physics-Informed AI comes in.

Instead of learning purely from data,

the model is constrained by physical laws.

---

## Option A (Recommended)

### LightGBM + Physics Constraints

Train normally.

Then penalize predictions violating

- Surface Energy Balance
- Urban Heat relationships

Much easier than PINNs.

---

## Option B (Research Level)

Physics-Informed Neural Networks (PINNs)

Uses

Neural Network

- 

Physics Loss

Pros

- Very novel

Cons

- Hard
- Slow
- Needs lots of tuning

Unless you're specifically publishing research,

I'd avoid PINNs.

# Module 5 — Multi-objective Optimization

This is **not AI**.

This is optimization.

You want

Maximize

- Cooling

Maximize

- Population protected

Minimize

- Cost

Minimize

- Maintenance

---

## Algorithm

NSGA-II

(Non-dominated Sorting Genetic Algorithm II)

Why?

Because you have

multiple objectives.

It is the standard algorithm used in urban planning.

---

Alternative

- MOEA/D
- SPEA2

I'd still choose

**NSGA-II**

# Recommendation Ranking

Now suppose NSGA-II returns

100 solutions.

How do you rank them?

Use

TOPSIS

or

AHP

Example

Solution A

Cheap

↓

Moderate Cooling

Solution B

Expensive

↓

Excellent Cooling

TOPSIS tells you

which is best overall.

# Uncertainty Estimation

Every prediction should include confidence.

Example

Instead of

```
Temperature

42°C
```

Return

```
Temperature

42°C ± 0.8°C

Confidence

94%
```

Use

- Bootstrap Ensembles
- Quantile Regression
- Monte Carlo Dropout (if using deep learning)

I'd recommend **Bootstrap Ensembles** because they're simple and work well with tree-based models.
